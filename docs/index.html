Theme Park Dispatch Controller

Real-Time Systems Final Capstone

This project simulates a real-time theme park ride dispatch controller using an ESP32-S3 and FreeRTOS.

Project Features

  • Emergency-stop interrupt on GPIO18
  • Binary semaphore and direct task notification comparison
  • Interrupt-latency measurement
  • Rate-monotonic task scheduling
  • Background-load testing

Results

Idle notification maximum latency: 30 microseconds.

Loaded notification maximum latency: 2682 microseconds.

Total periodic-task utilization: 33.28%.
